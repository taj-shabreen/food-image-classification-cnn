# Food Image Classification using CNN

## Overview

This project develops a Deep Learning based Food Image Classification System using Convolutional Neural Networks (CNNs).

The system automatically identifies and classifies food images into predefined categories using computer vision and deep learning techniques.

## Features

* Food image preprocessing
* CNN-based image classification
* Deep learning model training
* Performance evaluation
* Prediction visualization
* Multi-class food recognition

## Tech Stack

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Workflow

1. Load food image dataset
2. Preprocess images
3. Build CNN architecture
4. Train model
5. Evaluate performance
6. Predict food categories
7. Visualize results
